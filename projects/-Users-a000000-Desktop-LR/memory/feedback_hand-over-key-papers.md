When a paper is very likely important for the review's conclusion and I cannot obtain its text myself, give the user the title and DOI (not a long list) and they will fetch it, as with DREAM 32710834 on 2026-11-10.

**Why:** the user has institutional access (eduVPN) and can download PDFs that Cloudflare and paywalls block for me.
**How to apply:** do not spend effort fighting paywalls for decisive papers. Rank by importance, ask only for the few that matter, and mark the rest abstract-only. See [[feedback_science-first-routing]].
