用户(樊东篱)要求简历和自荐信在诚实前提下尽量好看:只写完成了什么,不主动写未完成/缺口/"没有…""非…"等否定句;负面信息留给 HR 面试时问到再答。HR 多非科研人员,专业细节数字(如 inter-arm angle)是多余信息,概括性描述更有效;但对决策有意义的结果(如 HBNet 路线评估 0 个满足→转向新方案)要保留。

**Why:** 中国求职环境里发现问题是 HR 的职责;主动自曝缺口会降低筛选通过率。
**How to apply:** 写/改任何简历、信时先过滤否定句和无意义数字;省略不等于虚构,仍不得升级角色或编造。面试风险清单单独给用户。
